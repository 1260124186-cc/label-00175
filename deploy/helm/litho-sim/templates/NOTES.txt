**  常用运维命令 **
*********************************************************************

查看所有 Pod:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/part-of=litho-sim

查看自动扩缩容状态:
  kubectl get hpa -n {{ .Release.Namespace }}
  kubectl get scaledobject -n {{ .Release.Namespace }}

查看 Celery Worker 队列长度:
  kubectl exec -it $(kubectl get pod -n {{ .Release.Namespace }} -l app.kubernetes.io/component=celery-worker -o jsonpath='{.items[0].metadata.name}') -- redis-cli -h {{ include "litho-sim.redis.host" . }} -a '{{ include "litho-sim.redis.password" . }}' llen celery

扩容 Worker 手动:
  kubectl scale deployment/{{ include "litho-sim.fullname" . }}-celery-worker --replicas=10 -n {{ .Release.Namespace }}

查看日志:
  API: kubectl logs -f -n {{ .Release.Namespace }} -l app.kubernetes.io/component=api
  Worker: kubectl logs -f -n {{ .Release.Namespace }} -l app.kubernetes.io/component=celery-worker

*********************************************************************
**  注意事项 **
*********************************************************************

1. 生产环境请务必修改以下默认密码：
   - global.jwtSecret
   - redis.auth.password
   - flower.auth.password

2. 首次安装请等待所有 Pod 就绪后再访问：
   watch kubectl get pods -n {{ .Release.Namespace }}

3. KEDA 自动扩缩容需要先安装 KEDA Operator：
   helm repo add kedacore https://kedacore.github.io/charts
   helm repo update
   helm install keda kedacore/keda --namespace keda --create-namespace

4. 启用 GPU Worker 需要：
   - 安装 NVIDIA GPU Operator
   - 配置 nvidia.com/gpu 污点和标签的节点
   - 设置 celeryWorker.gpu.enabled=true
